Claude Cowork Folder Structure Top Recommendations

A five-minute starter and the full recommended structure, blending the most popular patterns with the best ideas from the research. It is aimed at business professionals and non-technical users, though it is valuable for anyone using Claude Cowork. System-level and coding-project folder structures are available separately on request.

Recommended setupUpdated: 2026-06-19

A setup that blends the most popular patterns with the best ideas from the research. Start with the five-minute version, then grow into the full structure as you need it.

Quick Start (Five Minutes)

The smallest setup that works. Three things, nothing more.

1-Claude/        <- the one folder you point Cowork to
├── CLAUDE.md                     # short rules Claude reads each session
├── 1-About/                      # who you are and how you write
└── 2-Projects/                   # one folder per project
  1. Make one folder and point Cowork to it.
  2. Add a short CLAUDE.md with a few rules (who you are, how you write).
  3. Add 1-About/ for your identity and writing style.
  4. Add 2-Projects/, one folder per project.

That is enough to get real work done. Grow into the structures below only when you feel the need. That said, if you are a busy business professional, the full setup is strongly recommended from the start, because Claude does not fully support moving or renaming project folders. Workarounds exist, but in some cases you will lose your chat history. The good news: once you are organized like this, your files are easy to find and move, and it already puts you ahead of most people.

Expanded Folder Structure

The quick start plus the parts that help once you run several projects: shared context, top-level assets, an archive, and a few files per project. Projects stay simple here; the Full Recommended Folder Structure below drills into a project.

1-Claude/                                   <- you can have other workspaces for other parts of your life
└── 1-Claude-Cowork-Workspace/              <- the folder you point Cowork to
    ├── CLAUDE.md                           # lean rules, read every session (~200 lines max)
    ├── 1-Context/                          # shared reference Claude reads
    │   ├── About/                          # who you are and how you write
    │   │   ├── about-company.md
    │   │   ├── about-me.md
    │   │   ├── anti-ai-writing-style.md
    │   │   ├── my-rules.md
    │   │   └── writing-style.md
    │   ├── Sources/                        # sources.md, citations.md
    │   ├── Standards/                      # file-naming.md, folder-access.md
    │   └── Templates/                      # reusable starters
    ├── 2-Projects/
    │   └── Project-Name/                   # a project = a work area
    │       ├── CLAUDE.md                   # project rules
    │       └── Inputs/                     # input files for this project
    ├── 3-Assets/                           # Top assets (see project folders for all assets)
    ├── 4-Archive/                          # parked or no longer of value
    └── 5-Misc/                             # everything else of value

Full Recommended Folder Structure

The complete setup. Context gains an Agents folder and a Templates folder with sub-folders; projects split into Main and Other, each project expands into task sessions, inputs, assets and an archive; a 4-System area keeps backups of memory, status, learnings, tech notes and logs; plus Work Areas, a Library for bulk reference, Misc, Archive, and a filedrop inbox.

└── 1-Claude-Cowork-Workspace/              <- the folder you point Cowork to
    ├── AGENTS.md                           # for other AI tools (Claude itself uses CLAUDE.md)

    │   ├── 5-Tech/                         # tech support, tech stack, infrastructure, code library
    │   ├── 6-Other/                        # other system related files
    │   └── 7-Logs/                         # a copy of all conversations, for AI auditing/backup
    │       ├── 1-Chat-History/             # chat conversations, session logs, checkpoints, summaries
    │       ├── 2-Bugs-Reports/             # bugs, issues, AI gaps (business and coding)
    │       ├── 3-Fixes/                    # issue resolutions and fixes, for future reference
    │       └── 4-Changes/                  # file-change log, so you see what AI edited
    ├── 5-Work-Areas/                       # different job functions, operations, depts, clients, etc.
    │   └── Operations/                     # Legal, Finance, HR, Hiring, Meeting Notes, etc.
    ├── 6-Assets/                           # Top assets (see project folders for all assets)
    ├── 7-Library/                          # store large amounts of reference materials
    ├── 8-Misc/                             # everything else of value
    ├── 9-Archive/                          # parked or no longer of value
    └── filedrop/                           # optional area, for easy convenience, to drop new files for AI to sort
Task sessions. A task session is one Cowork chat. Each gets its own dated folder under 1-Project-Task-Sessions/ holding that chat's README.html, drafts, finals, and a CONTEXT.md, as shown in the project above. The Expanded Folder Structure keeps projects simple and does not show this level.
Other workspaces. The top 1-Claude/ folder holds this Cowork workspace and any others you want later. Keep a separate workspace for family, finances, or other personal files, so each stays clean. This reduces the chance of AI agents crawling the wrong files by accident.
AI preferences. Claude reads file names fastest when they are all lowercase, separated by dashes, and use the .md extension. The exception is ALL-CAPS names, which flag a file as important to read first. Mixed-case names and HTML are easier for people to read. The recommendations above aim to give the best of both: clear for you, fast for Claude.

The Key Files, in Plain Language
FileWhat it is
CLAUDE.mdThe rules Claude reads at the start of every session. Keep it short.
MEMORY.mdRunning memory Claude keeps across sessions.
AGENTS.mdRules for other AI tools. Claude itself reads CLAUDE.md, so this is for cross-tool use.
BRIEF.mdInside a project: the short what and why, written for Claude to read.
CONTEXT.mdInside a session: the goal and key facts for that one chat.
README.htmlThe human-facing front door for orientation. BRIEF.md is the version Claude reads.

Naming and Numbering
  • Number top folders to control order: 1-Context, 2-Projects, 3-Assets. (About lives inside Context.)
  • ALL CAPS for the important files: CLAUDE.md, README, MEMORY.md, AGENTS.md, BRIEF.md, CONTEXT.md.
  • lowercase-with-dashes for content files: about-me.md, writing-style.md, my-rules.md.
  • Dates as YYYY-MM-DD so they sort correctly.
