Master Sitemap: What Everyone Agrees On

One structure that blends what is most popular with what works best. Each line notes where the idea comes from. This is the common ground across the patterns below and on the Best practices page.

How often each folder bucket appears across the structures surveyed. Context and About, and Projects, are essentially universal.
1-Claude-Cowork-Workspace/
├── CLAUDE.md       # short rules, read every session     (all sources)
├── MEMORY.md       # memory across sessions
├── 1-About/        # identity and writing style          (Hassid: ABOUT ME)
├── 2-Context/      # shared reference                    (AI Corner: context)
├── 3-Projects/     # one folder per project              (every source)
├── 4-Outputs/      # finished deliverables               (Hassid/AC: outputs)
├── 5-Archive/      # parked work
├── Templates/      # reusable starters                   (Hassid: TEMPLATES)
└── filedrop/       # drop-and-sort inbox                 (helgejo: filedrop)
