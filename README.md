# Claude Cowork Folder Structure

A practical, shareable guide to organizing a Claude Cowork workspace: what Cowork is, the folder patterns people use, the principles behind them, and a setup you can copy. No coding needed.

## View it

- Open `Overview.html` in any browser, or
- Once published with GitHub Pages: `https://<your-username>.github.io/Claude-Cowork-Folder-Structure/`

## What's inside

| Page | What it covers |
|---|---|
| `Overview.html` | The 30-second version, key highlights, and how Cowork reads your folder. Start here. |
| `Popular-Patterns.html` | A master sitemap plus one folder tree per source. |
| `Best-Practices.html` | The ten folder systems in depth: PARA, Johnny Decimal, GTD, and more. |
| `Anthropic.html` | Official Anthropic facts, re-checked, with confidence labels. |
| `Recommendations.html` | A quick-start and the full recommended structure, with an alternative option. |
| `File-Details.html` | What goes in each file, with copy-paste templates. |
| `Sources.html` | Every source by category, with links. |

These are self-contained static HTML pages (inline CSS and JavaScript, inline SVG). No build step, no dependencies.

## Notes

- `index.html` redirects to `Overview.html` so the site root opens the guide.
- `.nojekyll` tells GitHub Pages to serve the files as-is.
