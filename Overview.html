The 30-Second Version

Claude Cowork is Anthropic's desktop agent for everyday knowledge work, "Claude Code for everything else." It reached general availability on macOS and Windows on April 9, 2026, and added Projects (persistent, self-contained workspaces with their own files, instructions, and memory) in March 2026.

Cowork works inside a folder you choose. Each session you point it to a folder and grant read, edit, or delete access, so the safest setup is one dedicated workspace folder, not your whole Documents drive.

Across every credible setup guide, the same skeleton appears: one parent folder with a few stable subfolders for context about you, projects, templates, and outputs, plus one or two always-read files at the root. The names vary; the buckets are remarkably uniform.

The single highest-leverage file is your about-me note: who you are, how you write, and the rules Claude must follow. Several guides call it "80 percent of prompting, done once." Templates are on the File details page.

Key Highlights
  • One parent folder, kept narrow. The most common beginner mistake is granting too-broad file access. Dedicate a single workspace folder.
  • Four near-universal folders: some mix of Context and About, Projects, Templates, and Outputs appears in nearly every guide.
  • A few small files do most of the work: about-me, writing-style, and rules. Keep each short; Cowork re-reads them often.
  • Anti-examples beat positive ones. Telling Claude what to reject (banned phrases, AI tells) does more than adding more positive samples.
  • A root CLAUDE.md plus MEMORY.md pair the rules with a running notepad Claude keeps across sessions.
  • Projects are local, not cloud-synced. All project data stays on your machine.
  • Start tiny. Add subfolders only when a pattern repeats. Do not over-engineer the tree.

How Cowork Reads Your Folder

Three zones: files Cowork reads every session (keep these tiny), files loaded on demand when you scope a task, and where finished work is written.

Solid arrows: auto-read every session. Dashed: loaded on demand. Full detail on the File details page.
Auto-Read

Your context files and root CLAUDE.md / MEMORY.md. Pulled every session, so keep them small.

On-Demand

Templates and project folders. Referenced when you point Cowork to them. Can be large.

Write-Only

Outputs and archive. Cowork drops finished work here; you do not hand-curate.
